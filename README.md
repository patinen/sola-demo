# SOLA Studio

Independent Next.js concept site for a fictional Finnish beauty studio.

## Run locally

`npm ci && npm run dev`

Validate with `npm run lint`, `npm run typecheck`, and `npm run build`.

## Coolify

Deploy this directory as its own repository using the included Dockerfile. Set build pack to Dockerfile, expose port `3000`, and configure the domain `sola.pat1.online` when ready. No environment variables, persistent volumes, or databases are required.
